# Vendor Performance Dashboard

## 📊 Project Overview

This Power BI project analyzes vendor performance across key operational and quality metrics. The dashboard provides a clear view of vendor risk, SLA compliance, delivery performance, contract value, quality scores, and defect rates.

The goal of the project is to demonstrate how vendor data can be transformed into an interactive dashboard that supports performance monitoring and vendor management decisions.

## 🎯 Business Objective

The dashboard was designed to help users:

- Monitor overall vendor performance
- Identify high-risk vendors
- Track SLA compliance
- Compare on-time and delayed deliveries
- Evaluate vendor quality scores
- Monitor defect rates
- Analyze vendors by region, category, and risk level

## 🔑 Key KPIs

The dashboard tracks:

- **Total Vendors**
- **Total Contract Value**
- **Average SLA Compliance**
- **Average Quality Score**
- **High Risk Vendors**

## 📊 Dashboard Visualizations

### Vendor Risk Distribution
Shows the distribution of vendors across different risk levels, allowing high-risk vendors to be identified quickly.

### SLA Compliance by Vendor
Compares SLA compliance across vendors to identify differences in service performance.

### On-Time vs Delayed Deliveries
Compares on-time and delayed deliveries across vendors to support delivery-performance analysis.

### Vendor Defect Rate
Displays vendor defect rates to help identify potential quality issues.

## 🔍 Interactive Filters

The dashboard includes slicers for:

- **Region**
- **Category**
- **Risk Level**

These filters allow users to explore vendor performance from different perspectives.
